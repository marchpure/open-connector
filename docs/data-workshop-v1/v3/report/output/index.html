Frozen contract surfaces

OpenConnector API Web+BFF API Shared schemas Authorization Error envelope Routes Test matrix

IdentityProviderConfig

Tenant, issuer, audiences, JWKS URI, UserPool reference, stable subject/group/tenant claims, status and refresh state.

AuthContext

Stable tenant, subject and group IDs plus issuer, audience and authentication time—never the raw token.

AccessGrant + RoleDefinition

Connection-scoped allow or deny for a user/group using reader, operator or explicit custom Actions.

PolicyDecision

Allow/deny, target, matched grants and roles, stable reason code and policy version for explanation and audit.

OpenViking has one legal product mapping: Profile / directory / resource → Knowledge ResourceRef → Skill Context. S1S2
